# JM Ali Project Notes

## Project
- **Name:** JM Ali
- **Goal:** Build an online grocery store for household and restaurant customers.
- **Version:** v0.0.1
- **Status:** Frontend prototype

## Current Scope
- Customer storefront homepage and product browsing
- Product categories for fruits, vegetables, and seafood
- Admin pages for customers, inventory, orders, products, reports, and settings
- Static product imagery and frontend styling

## Next Milestones
1. Finish and polish the storefront homepage.
2. Complete product browsing, product details, and cart workflows.
3. Build the customer checkout and order confirmation flow.
4. Connect the admin dashboard to shared product, inventory, and order data.
5. Replace browser-only storage with a backend API and database.

## Long-Term Direction
JM Ali should support daily price updates, stock management, restaurant bulk pricing, online orders, and order status tracking. A mobile app can reuse the backend after the web storefront is established.
